## Overview

This repository contains Python implementations of algorithmic problems solved on LeetCode. The problem set spans fundamental and intermediate computer science patterns including array transformations, hash-map lookups, stack evaluation, two pointers, sliding window, linked list pointer manipulation, and bit arithmetic. Each solution is written with attention to time and space complexity trade-offs for technical coding interview readiness.
